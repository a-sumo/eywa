# Eywa has moved

Eywa was an experimental multi-agent coordination project. Its focused successor is **Swarmline**:

## [Open Swarmline](https://github.com/a-sumo/swarmline)

Swarmline provides explicit coordination primitives for AI agents and a human-readable event line for observing their work.

This repository is retained as an archive. Earlier Eywa experiments remain available in the Git history.
